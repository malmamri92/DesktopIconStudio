# 🖥️ استوديو أيقونات سطح المكتب — Desktop Icon Studio v2

برنامج احترافي للتحكم الكامل في أيقونات سطح المكتب على **ويندوز 10/11**،
مكتوب بلغة بايثون و**لا يحتاج أي مكتبات خارجية** (يعمل ببايثون القياسي فقط).

---

## ✨ المزايا

| الميزة | الوصف |
|---|---|
| 📋 عرض الأيقونات | قائمة بكل الأيقونات مع أسمائها وإحداثياتها الحية |
| 🗺️ خريطة مصغّرة | مخطط مرئي لسطح المكتب — انقر لتحديد أيقونة واسحبها لتحريكها |
| 📍 التحريك | بالأسهم (بخطوة تختارها) أو بإدخال الإحداثيات X/Y مباشرة |
| 🔍 حجم الأيقونات | أي قيمة من 16 إلى 256 بكسل — بضبط دقيق أو بخطوات ＋/− |
| ↔️ المسافات | تحكم مستقل في المسافة الأفقية والرأسية بين الأيقونات |
| 🔳 ترتيب تلقائي | شبكة أبجدية / دائرة / صف علوي أو سفلي / عمود جانبي / توسيط |
| 〰️ موجة | ترتيب الأيقونات على شكل موجة |
| 🌀 حلزون | ترتيب الأيقونات على شكل حلزون |
| 📂 تجميع حسب النوع | تجميع الأيقونات في أعمدة حسب امتداد الملف |
| 💾 التخطيطات | حفظ تخطيطات متعددة واستعادتها، مع تصدير/استيراد JSON |
| 🖥️ دقة الشاشة | حفظ/استعادة تلقائية لكل دقة شاشة |
| 🙈 إخفاء/إظهار | إخفاء كل أيقونات سطح المكتب أو إظهارها فورًا |
| 🔔 أيقونة بجانب الساعة | System Tray مع قائمة سريعة |
| ⌨️ اختصارات عالمية | Ctrl+Alt+S فتح، H إخفاء/إظهار، R استعادة الدقة، W موجة، P حلزون |

## ⚠️ خطوة ضرورية قبل الاستخدام (مرة واحدة فقط)

حتى تثبت الأماكن التي تحددها للأيقونات، يجب إيقاف **الترتيب التلقائي** في ويندوز:

1. زر **أيمن** على مكان فارغ في سطح المكتب
2. اختر **عرض** (View)
3. ألغِ تفعيل **«ترتيب الأيقونات تلقائيًا»** (Auto arrange icons)

> بدون هذه الخطوة سيعيد ويندوز الأيقونات إلى أماكنها تلقائيًا بعد أي تحريك.

## 🚀 التشغيل

المتطلبات: **Python 3.8 أو أحدث** على ويندوز.

```powershell
python desktop_icon_studio.py
```

### تحويله إلى ملف تنفيذي (اختياري)

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --icon icon.ico --name "DesktopIconStudio" desktop_icon_studio.py
```

سينتج الملف التنفيذي في مجلد `dist`.

## 🛠️ كيف يعمل؟ (للمطورين)

- يحدد البرنامج نافذة أيقونات سطح المكتب `SysListView32` (تحت `Progman` أو `WorkerW`).
- قراءة الأسماء والمواقع تتم عبر رسائل `LVM_GETITEMTEXTW / LVM_GETITEMPOSITION`
  مع ذاكرة مشتركة داخل عملية Explorer (`VirtualAllocEx` + `ReadProcessMemory`).
- التحريك عبر `LVM_SETITEMPOSITION`، والمسافات عبر `LVM_SETICONSPACING`.
- تغيير الحجم يحاكي **Ctrl + عجلة الفأرة** فوق سطح المكتب مع قراءة القيمة
  الحالية من السجل `HKCU\Software\Microsoft\Windows\Shell\Bags\1\Desktop`
  حتى الوصول للحجم المطلوب بدقة.
- أيقونة بجانب الساعة واختصارات الكيبورد تُدار عبر `Shell_NotifyIconW` و
  `RegisterHotKey` باستخدام `ctypes` فقط.
- البرنامج واعٍ بـ DPI فتكون الإحداثيات بالبكسل الفعلي حتى مع تكبير الشاشة.

## ❓ استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الأيقونات تعود لمكانها بعد التحريك | أوقف «ترتيب الأيقونات تلقائيًا» (انظر الأعلى) |
| «تعذّرت قراءة الحجم الحالي» | استخدم زرَّي ＋/− بدل المنزلق |
| لا تظهر أيقونات في القائمة | تأكد أن الأيقونات ظاهرة: زر أيمن ← عرض ← إظهار أيقونات سطح المكتب |
| تغيّرت أماكن الأيقونات بعد تغيير دقة الشاشة | احفظ تخطيطًا قبل التغيير واستعده بعده — أو فعّل الحفظ التلقائي للدقة |
| اختصار الكيبورد لا يعمل | قد يكون مستخدمًا من برنامج آخر؛ جرّب اختصارًا آخر |
